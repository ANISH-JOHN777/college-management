    1. Linear Search

    Sequentially checks each element in the array until the target key matches.

    linearSearch(array, target, key):
    for i = 0 to length(array) - 1:
        if array[i][key] == target:
            return array[i]
    return null

    2. Insertion Sort

    Sorts student array alphabetically by name in-place without built-in sort functions.

    insertionSort(array, key):
    for i = 1 to length(array) - 1:
        currentItem = array[i]
        j = i - 1
        while j >= 0 and array[j][key] > currentItem[key]:
            array[j + 1] = array[j]
            j = j - 1
        array[j + 1] = currentItem
